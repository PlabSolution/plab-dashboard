# PLAB 멘토링 트래커 (회사 계정 이관본)

멘토링 기업의 회차별 진행·서류 제출 현황을 관리하는 내부 대시보드예요.
화면은 GitHub Pages(`index.html` + `assets/`), 서버는 구글 시트에 붙은 Apps Script(`src/`)예요.

## 들어 있는 기능

- 취합현황 / 업로드현황(자료 제출) 표
- 드라이브 동기화, 취합현황 업데이트, 매일 새벽 4시 자동 동기화
- 회차 관리(프로그램 탭)
- 로그인, 권역별 열람, 사용자 관리
- 지연 판정과 기준일 설정(설정 탭), 세션 수 설정
- 변경 이력
- 보고서(회차별·권역별 비교)와 엑셀 내보내기

개인 계정 버전에서 뺀 기능: 알림센터, 기업 자동 리마인더, 일일 요약 메일, 고객사 관리,
세션 현황 차트, 세션 커리큘럼, 예시 데이터, 화면에서 서버 주소 바꾸기, 옛 로그인 방식(아이디·비밀번호를 매 요청에 보내던 방식).
메일 발송 기능이 없어져서 Gmail 발송 권한도 요청하지 않아요.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `assets/` | 화면(GitHub Pages에 올리는 부분) |
| `src/config.js` | 시트 이름, 컬럼, 계정 목록, 세션 수·지연 기준 설정 |
| `src/auth.js` | 로그인, 토큰, 비밀번호 잠금(5회 실패 시 10분), 사용자 관리 |
| `src/sheet.js` | 시트 읽기·쓰기, 변경 이력 |
| `src/round.js` | 회차 관리 |
| `src/drive.js` | 드라이브 폴더 스캔과 동기화 |
| `src/syncinfo.js` | 마지막 동기화 결과 기록 |
| `src/triggers.js` | 새벽 자동 동기화 트리거 |
| `src/main.js` | 웹 앱 진입점(doPost) |
| `appsscript.json` | Apps Script 설정(Drive 고급 서비스 v3 포함) |

비밀번호와 폴더 ID는 코드에 없고, 모두 Apps Script의 **스크립트 속성**에만 저장돼요.
저장소가 공개여도 코드만으로는 로그인할 수 없어요.

## 스크립트 속성

| 이름 | 필수 | 설명 |
|---|---|---|
| `PW_<아이디 대문자>` | 예 | 계정 비밀번호. 예: `PW_ADMIN_AI` |
| `DRIVE_FOLDER_ID` | 예 | 1회차 기업 폴더들이 들어 있는 드라이브 폴더 ID |
| `USERS_JSON` | 아니요 | 계정 목록. 없으면 코드의 기본 5개 계정을 써요 |

`SESSION_COUNT`, `FLAG_THRESHOLDS`, `LAST_SYNC_*`, `TOKVER_*` 등은 사용하면서 자동으로 생겨요.
